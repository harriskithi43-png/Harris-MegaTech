# Harris Kithi — IT Technician & Software Developer Portfolio

A responsive personal portfolio website showcasing computer repair and maintenance, networking, database management, web development, Java/Android development and technical support.

## Website files
- `index.html` — portfolio content and page structure
- `css/style.css` — responsive dark theme and layout
- `js/main.js` — mobile navigation and automatic footer year

## Preview locally
1. Download and extract this project.
2. Open the extracted folder.
3. Double-click `index.html` to preview in your browser.
4. To edit, open the folder in Visual Studio Code.

## Publish with GitHub Pages
1. Create a public GitHub repository named `harris-kithi-portfolio` (or choose another name).
2. Upload the contents of this folder to the repository root. Keep `css/` and `js/` folders.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the Pages deployment. GitHub will display the published website URL in the Pages settings.

## Personalize before publishing
In `index.html`, replace:
- `YOUR-EMAIL@example.com` with the email address you want employers to use.
- `YOUR-GITHUB-USERNAME` with your actual GitHub username.
- The LinkedIn link with your own profile URL, or remove that link if you do not use LinkedIn.

## Important project accuracy note
The Asset Tracking Android App is labelled **In Development**. Other project cards are prompts for case studies to add. Update them with your actual work, screenshots, repositories and test results. Do not claim unfinished work as completed.

## Good evidence to add to every project
- The problem or goal
- Tools and technologies used
- Your role and steps completed
- Screenshots, diagrams or sample output
- Testing performed and results
- What you learned and what you would improve next
